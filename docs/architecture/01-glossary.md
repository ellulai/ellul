# Glossary

Terms you will see across the codebase and v2 docs. Each entry includes a short definition and where to dig deeper.

## A

**Agent** — The AI coding assistant (Claude, Codex, Gemini, OpenCode CLI) running on the VPS in a per-project namespace. Treated as a hostile actor by the security model. See [security/00-overview.md](../security/00-overview.md).

**Agent Bridge** — Localhost service on port 7700. WebSocket gateway that brokers chat messages between browser and CLI sessions. Spawns CLIs inside per-project namespaces. Source: `packages/vps/src/services/backends/agent-bridge/`.

**Anchor** — The persistent process that holds a project's mount and PID namespaces open. Killed on teardown.

**Authenticated Origin Pull (AOP)** — Cloudflare feature that presents a Cloudflare-issued client cert to origin servers. Caddy validates against `cf-origin-pull-ca.pem`. Combined with strict SNI, this is the origin's mTLS gate.

## B

**Block migration** — Moving an encrypted volume's contents from one VPS to another by reading raw LUKS ciphertext blocks, uploading to R2, downloading on target, and resuming with the same LUKS key. Plaintext is never seen by either side. See [storage/04-block-migration.md](../storage/04-block-migration.md).

**Boot partition** — `/etc/ellul-bootstrap/`, lives on the unencrypted root filesystem. Holds server identity (server-id, ML-DSA-44 heartbeat key, ML-KEM-1024 node key, AI proxy bearer token). Survives every reboot, never vault-bound. See [storage/01-vault-layout.md](../storage/01-vault-layout.md).

**Booster (cloud-init)** — A <2KB cloud-init payload that fits in Hetzner's user_data limit. Hardens SSH, downloads the full provisioning script, runs it under a fail-closed watchdog. Source: `apps/api/src/provisioning/cloud-init.ts:189`.

**Bootstrap token** — Single-use bearer token (5-min TTL + 5-min grace) embedded in cloud-init. The VPS uses it once to call `/api/servers/:id/bootstrap`, exchanges its public key for an ML-KEM-encrypted secret bundle. Burned on completion.

**bwrap** — `bubblewrap`, an unprivileged sandbox tool used by some CLI agents (codex, claude-code). Requires AppArmor profile under Ubuntu 24.04+ to allow user namespaces.

## C

**Caddy** — The reverse proxy on port 443. Terminates mTLS, runs forward_auth against Sovereign Shield, routes to backends. Config at `/etc/caddy/Caddyfile` (regenerated by `caddy-gen`).

**Caddy-gen** — TypeScript CLI at `/usr/local/bin/ellul-caddy-gen` that generates the Caddyfile from runtime parameters (origin tag, custom domain, deployment model). Source: `packages/vps/src/services/gateway/caddy-gen/`.

**Canary / early / stable / late** — Rollout states for fleet manifests. Each manifest progresses pending → canary → early → stable → late, with operator-controlled promotions. Cohort-pinned VPSes stick to specified state.

**Capabilities** — Strings like `database:read`, `secrets:env_inject`, `deployment:deploy_trigger`. Tools advertise required capabilities; the gate system maps capabilities to gate types.

**CLI session** — A persistent CLI instance (Claude, Codex, etc.) bound to a chat thread. State stored in per-thread isolated HOME at `~/.ellul/threads/<threadId>/`.

**Cloud Sandbox** — Sandboxed agent execution without the full workbench. Same VPS infrastructure, different feature flags.

**Cloud-init** — First-boot configuration mechanism on Linux cloud images. ellul.ai uses it to deliver the booster.

**Cohort pin** — A flag on a VPS that locks it to a specific rollout state (e.g., always early). Used for pre-staging upgrades on test fleets.

**Comms channel** — In org mode, a vault directory bind-mounted into multiple team namespaces to enable inter-team communication. Three types: `team_internal`, `hierarchical`, `cross_team`. See [products/04-agent-adapter.md](../products/04-agent-adapter.md).

**Core runtime bundle** — The grouped manifest component (`@ellul.ai/core-runtime-bundle`) that ships file-api, agent-bridge, term-proxy, mcp-relay, sovereign-shield, and several wrapper scripts in lockstep. Single version (`packages/vps/core-runtime-bundle/package.json`) for all of them. See [operations/02-manifest-system.md](../operations/02-manifest-system.md).

**Cross-project access** — A `cross_project_access` row in the API DB granting one project read access to another's source code. Surfaces inside the agent's namespace as a read-only `.shared/<slug>` snapshot (rsync, not bind mount).

## D

**DIRECT command** — A command type the enforcer executes locally (without going through file-api HTTP). Examples: `wake-mount`, `luks-rekey`, `block-migrate-upload`, `b2b-sandbox-destroy`. See [runtime/06-direct-commands.md](../runtime/06-direct-commands.md).

**Deployment model** — How public traffic reaches the VPS. Three modes: `proxied` (Cloudflare edge + mTLS), `direct` (Let's Encrypt ACME, no Cloudflare), `gateway` (Cloudflare Worker + resolveOverride to origin tag). On the VPS this is binary: `proxied | direct`. See [networking/01-gateway-routing.md](../networking/01-gateway-routing.md).

## E

**ellul-env** — The bash script that is the enforcer daemon. Hot-shipped as a manifest component. After updating ellul-env, the enforcer execs the new version (replaces PID 1 inside systemd notify).

**Enforcer** — Root daemon on the VPS. Heartbeats every 30s, executes commands from the API queue, monitors service health, manages vault mounts, applies manifest updates. Bash daemon assembled from modular libraries in `packages/vps/src/services/daemons/enforcer/lib/`.

**Entitlements** — Per-server resource limits (max projects, max previews) signed by the API and applied locally by the enforcer. Separate from the manifest update system.

**Egress allowlist** — The list of destinations the agent (or namespaced project) is permitted to reach. Implemented via Warden DNS/proxy plus iptables-restricted `ellul-egress` ipset.

## F

**File API** — Localhost service on port 3002. Code browser, file tree, app detection, preview management, WebSocket events. Source: `packages/vps/src/services/backends/file-api/`.

**Forward_auth** — Caddy directive that delegates authentication to a sub-request. ellul.ai's pattern: Caddy → Shield `/_auth/session` → Caddy decorates upstream request with `X-Auth-User` (and `X-Auth-Tier`, etc.) header.

**Free tier** — Cloud Platform Hobby plan ($0). User: `coder`. Firewall: `full_ironclad`. cgroup-limited (CPU 80%, memory MemoryHigh=75% RAM). Localhost ports tightly whitelisted.

## G

**Gate** — A user-controlled permission that the agent must hold to perform a privileged action. Types: `db_read`, `db_write`, `db_migrate`, `logs`, `env`, `git`, `deploy`, `exec`, `wallet_spend`, `vault_read`. TTL varies. See [security/03-sovereign-gates.md](../security/03-sovereign-gates.md).

**Gate token** — A short-lived token issued by Shield after the user approves a gate request. The agent presents it when calling the gated tool.

**Gateway model** — Deployment model that uses the Cloudflare Worker + resolveOverride. The customer's main domain `<id>-srv.ellul.ai` is proxied via the Worker, which routes to per-IP origin record `o-<tag>.ellul.ai`.

**Glass box** — The mount-namespace isolation pattern: source code read-only, data vault private, logs redacted, /tmp ephemeral. Apps see code but cannot modify it; agent sees code R/W but not its data.

## H

**Heartbeat** — VPS-to-API ping every 30 seconds. Carries telemetry (CPU, RAM, services, security state) signed with ML-DSA-44. Response is discarded; commands flow through a separate signed-envelope queue. See [runtime/07-heartbeat-protocol.md](../runtime/07-heartbeat-protocol.md).

**Hetzner abuse** — Account suspension triggers from cloud providers (mining, spam, DDoS, port scanning). The platform's defense layer; see [abuse-protection/00-overview.md](../abuse-protection/00-overview.md).

**Hibernate** — Scale-to-zero state. Cloud server deleted, volume preserved. Triggered by idle-manager cron. See [lifecycle/02-hibernate.md](../lifecycle/02-hibernate.md).

**Hot California** — A no-longer-default Warden mode that did MITM TLS interception. Disabled because incompatible with namespaces and added 5-10s per TLS handshake. Replaced by `tunnel_guard`.

## I

**Identity pinning** — `/etc/ellul/owner.lock` written once at provisioning with `chattr +i`. Records the cloud-server ID. If the same volume attaches to a different server, the file mismatches and emergency lockdown triggers.

**IPC token** — File at `/run/shield/internal-<service>.token`. Used for HMAC verification on internal HTTP calls. Regenerated on each boot. Service must have supplementary group `shield-ipc` to read.

**Ironclad** — The free-tier security profile (`full_ironclad`). Includes Warden tunnel-guard mode, cgroup limits, narrow sudo, locked binaries (su=000, iptables=700, etc.). Source: `packages/ironclad/`.

## J

**JWS** — JSON Web Signature compact serialization (`header.body.signature`). Used for manifest signing (ML-DSA-65) and entitlement signing.

## K

**KV (Cloudflare)** — Key-value store accessed by the gateway Worker. Holds `shortId → {"s":"active","o":"<ipTag>"}` and `customHostname:<host> → {"shortId":"..."}`. Reconciled by `apps/api/src/cron/gateway-reconciler.ts`.

## L

**LUKS** — Linux Unified Key Setup. The encrypted volume format. Modes: `standard` (platform key only, slot 0), `enhanced` (platform + user PRF, slots 0+1), `sovereign` (user PRF only, slot 0 deleted from header). See [storage/02-encrypted-volumes.md](../storage/02-encrypted-volumes.md).

## M

**Manifest** — Signed JSON blob describing fleet update components (versions, sha256, restart units). Versioned monotonically with `previousVersion` chain. ML-DSA-65 signed.

**Migrate role** — A temporary PostgreSQL role created on `db_migrate` gate grant. Has DDL permissions for the duration of the gate (5min default). Three-step atomic teardown: `ALTER NOLOGIN`, `pg_terminate_backend`, `DROP ROLE`.

**MCP relay** — The MCP (Model Context Protocol) bridge daemon. Spawned by agent-bridge, listens on port 7702 (0.0.0.0), reachable only from project namespace veths. HMAC-token authenticated.

## N

**Namespace** — Linux kernel isolation primitive. ellul.ai uses three: mount, PID, network (UTS and IPC remain shared). Per-project. Created by `ellul-agent-namespace` script. See [isolation/01-namespace-script.md](../isolation/01-namespace-script.md).

**Namespace IP** — Deterministic 10.x.x.x derived from HMAC-SHA256(jwt-secret, projectSlug). Both the namespace and host-side veth get IPs in a /30 from this range.

## O

**OpenClaw** — Per-project agent-orchestration daemon. Spawned by agent-bridge in each project's namespace. Manages CLI sessions, persistent context, per-channel multi-account state.

**Origin tag** — Lowercase hex encoding of an IPv4. `192.168.0.1` → `c0a80001`. Written to `/etc/ellul/origin-tag` by enforcer and read by `caddy-gen` to populate the site block address `o-<tag>.ellul.ai:443` for strict SNI matching. See [networking/03-origin-tags.md](../networking/03-origin-tags.md).

## P

**Paid tier** — Cloud Platform paid plans (Starter/Standard). User: `dev`. Firewall: `relaxed`. No cgroup limits.

**Passkey** — WebAuthn credential bound to the user's hardware authenticator (Touch ID, Windows Hello, security key). Required for `web_locked` and `private_locked` tiers. Public key stored in Shield's SQLite DB.

**Per-project namespace** — See *Namespace*. The Linux namespaces created per project to isolate the agent's view of filesystem, processes, and network.

**Port registry** — `packages/vps/src/services/shared/ports.ts`. Single source of truth for every port used. Build-time collision check via `assertNoPortCollisions()`.

**PoP** — Proof of Possession. Non-extractable ECDSA P-256 key generated in browser, signs WebSocket challenges. Defends against stolen-cookie attacks in `web_locked` tier.

**private_locked** — The strictest security tier, equivalent to sovereign mode. LUKS slot 0 (platform key) removed; only user PRF unlocks. Wake requires user passkey. See [security/05-tiers.md](../security/05-tiers.md).

**Provisioning** — The first-boot setup script that turns a fresh Linux VM into a functional ellul.ai VPS. Sequenced in sections: header → user → swap → directories → files → packages → bootstrap → boot-config → caddy → security → memory-tuning → services → attestation → footer.

**ptrace_scope** — Linux kernel sysctl `kernel.yama.ptrace_scope`. Set to `1`: only ancestor processes can ptrace. Prevents agent from reading sibling processes' `/proc/<pid>/environ`. See [security/01-kernel-hardening.md](../security/01-kernel-hardening.md).

## R

**resolveOverride** — Cloudflare Worker `fetch` option that re-resolves a hostname to a different DNS name and rewrites SNI/Host. Used to route per-id subdomains through shared origin records.

**Reconciler** — `apps/api/src/cron/gateway-reconciler.ts`. Runs every 10 minutes. Ensures Cloudflare KV and DNS records match desired state from the API DB.

## S

**Sandbox-scoped capability** — Capability classification used by cross-project gate enforcement. Capabilities like `database:*`, `secrets:*`, `deployment:*`, `observability:*` are sandbox-scoped: they cannot operate on other projects' data even if the agent has read access to the source.

**Shield (Sovereign Shield)** — The auth and gate service on port 3005. Owns passkeys, sessions, audit log, gate decisions, secrets vault. Runs as separate `shield-runner` user. Source: `packages/vps/src/services/auth/sovereign-shield/`.

**Shield Gateway** — A standalone Sovereign Shield deployment for self-hosted clouds (the $10/mo product).

**shield group** — Linux POSIX group. Members can read sensitive files (`/etc/ellul/jwt-secret`, `/etc/ellul/secrets/*`, `/etc/ellul-bootstrap/node.key`). Sovereign Shield is a member; agent (dev/coder) is NOT.

**shield-ipc group** — POSIX group for read access to `/run/shield/internal-*.token`. Services that need to call internal endpoints with HMAC have this as a supplementary group.

**SNI** — Server Name Indication, the TLS handshake extension that names the requested hostname. Caddy's strict SNI matching depends on the SNI value being in the site block's address list.

**Standard tier** — Default security tier. Username/password OR passkey login. JWT-based sessions. Less restrictive than `web_locked`/`private_locked`.

**Sovereign Gate kmod** — Optional Linux kernel module (`packages/sovereign-gate-kmod`) that performs hardware-interrupt-driven cryptographic challenges to detect agent process tampering.

**SVC_USER** — The agent's Linux user. `coder` for free tier, `dev` for paid. Set early in provisioning header section.

## T

**Term proxy** — Localhost service on port 7701. Authenticates terminal WebSocket connections via Sovereign Shield, routes to dynamic ttyd ports. Source: `packages/vps/src/services/gateway/term-proxy/`.

**Tier** — Security tier, distinct from billing tier. Three levels: `standard`, `web_locked`, `private_locked`. See [security/05-tiers.md](../security/05-tiers.md).

**Tunnel Guard** — Warden's domain-blocking mode. Inspects TLS SNI without MITM. Blocks mining pools, tunnel services (ngrok, Tailscale), unauthorized cloud APIs. Default for both free and paid tiers.

## V

**Vault** — `$SVC_HOME/.ellul-vault/`, an LUKS2-encrypted directory bind-mounted to system paths (`/etc/ellul`, `/etc/caddy`, `/var/lib/postgresql`, etc.). Persistent across hibernation/wake.

**Veth pair** — Virtual Ethernet pair connecting host network namespace to project namespace. Named `ea-<slug>` host-side, internal name inside namespace.

## W

**Wake** — Resurrecting a hibernated server. User-initiated; either claims a warm pool VM or cold-provisions. Heartbeat-driven reconciliation completes the wake (attach volume → mount → restore identity → re-register pubkey → activate). See [lifecycle/03-wake.md](../lifecycle/03-wake.md).

**Warden** — Go service in `packages/ironclad/warden/`. Two roles: DNS resolver (port 5353) with blacklist, and transparent proxy (port 8080) with SNI-based blocking. Free-tier traffic is iptables-redirected here; paid-tier traffic to flagged domains is also redirected.

**Watchdog** — VPS daemon on port 7710. Runs interactive CLI auth sessions (claude setup-token, codex login) under PTY wrapper, exposes `/agents/auth/...` SSE endpoints. Reports OpenClaw daemon health.

**web_locked** — Security tier requiring passkey login + PoP signing on WebSockets. SSH disabled by default. JWT cookies are augmented with PoP-signed challenges every 5 minutes. See [security/05-tiers.md](../security/05-tiers.md).

## Z

**ZeroClaw** — The original name for OpenClaw; some code paths still use it. Same component, different brand. Will be renamed completely in a future cleanup pass.
