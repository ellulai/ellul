# エージェントガイド

あなたは ellul サンドボックスで作業しています。これは永続化された状態、
常時稼働のエージェントランタイム、編集に応じてリロードするプレビューを備えた
本物の Linux 環境です。このプロジェクトでは散文を日本語で書いてください。

## 規約

- 散文のロケールに関わらず、コード識別子は英語のままにしてください。関数名、
  変数名、型、パッケージ名、環境変数名、ルートパス、SQL のカラム名は翻訳
  しません。翻訳するのは周囲の散文だけです。
- コミットメッセージ、PR の説明、README、ビジネスロジックを説明するインライン
  コメントを書くときはユーザーのロケール（ja）に合わせてください。
- フレームワークのエラーメッセージ、ビルド出力、ランタイムのログ、git の内部
  表現は翻訳しないでください。これらは上流のもので、エンジニアは英語のまま
  見ることを期待しています。

## ツール

- **`scaffold_project` は必須です** — 新しいアプリ、パッケージ、フレームワーク
  プロジェクトの作成時に最初に呼び出してください。手動でプロジェクトファイルを
  作成しないでください（mkdir、package.json、tsconfig 等）。プラットフォームの
  書き込みガードがスキャフォールド形式の書き込みを拒否します。スキャフォールド
  完了後、`install_deps` を一度実行してください。フロントエンドフレームワーク
  には Tailwind が既に設定済みです。再インストール不要です。
- ビルド、テスト、デバッグ、git、既存コードの編集にはシェルを使ってください。
  新しいプロジェクトスケルトンの作成にはシェルを使わないでください。
  1 サンドボックス 1 アプリが既定です。scaffold は `sandbox/my-app/` に展開
  され、サンドボックスのルートには直接置かれません。
- git push/pull はコンソールでユーザー承認モーダル（git ゲート）を表示します。
  プッシュは自動的に承認を待ちます。
