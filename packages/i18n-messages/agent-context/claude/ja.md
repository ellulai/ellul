# Claude Code 用プロジェクトコンテキスト

あなたは ellul ワークスペース上で動作するエージェントです。このプロジェクト
では、人間が読むテキスト — チャット返信、コミットメッセージ、PR の説明、README、
ビジネスロジックを説明するインラインコメント — は日本語で書いてください。

ロケールに関わらず、コード識別子は英語のままにしてください。変数名、関数名、型、
パッケージ名、フレームワークの慣例、REST エンドポイント、SQL のカラム名、npm
パッケージは翻訳しません。翻訳するのは周囲の散文だけで、シンボル自体は英語の
ままです。

## このサンドボックスでの作業

- **`scaffold_project` は必須です** — 新しいアプリ、パッケージ、フレームワーク
  プロジェクトの作成時に最初に呼び出してください。手動でプロジェクトファイルを
  作成しないでください（mkdir、package.json、tsconfig 等）。プラットフォームの
  書き込みガードがスキャフォールド形式の書き込みを拒否します。スキャフォールド
  完了後、`install_deps` を一度実行してください。
- フロントエンドフレームワークには Tailwind が既に設定済みです。再インストール
  は不要です。
- 1 サンドボックス 1 アプリが既定です。scaffold は `sandbox/my-app/` に展開され、
  サンドボックスのルートには直接置かれません。
- シェルは既存コードの編集、テスト、ビルド、デバッグ、git に使ってください。
  新しいプロジェクトスケルトンの作成には使用しないでください。
- git push/pull はコンソールでユーザー承認モーダル（git ゲート）を表示します。
  プッシュは自動的に承認を待ちます。

## 散文を書くとき

- このリポジトリで人間が読むもの — コミット、PR の本文、README、ビジネス
  ロジックのコメント — はユーザーのロケール（ja）に合わせてください。
- フレームワークのエラーメッセージ、ランタイムのログ、ビルド出力、git の
  内部表現は翻訳しないでください。これらは上流のもので、エンジニアは
  そのまま見ることを期待しています。
- 周囲の散文を翻訳してもコード識別子は英語のまま残してください。
