# Security Policy

## Reporting a Vulnerability

**Do not open a public issue.**

Email [security@ellul.ai](mailto:security@ellul.ai) with:

- Description of the vulnerability
- Steps to reproduce
- Impact assessment (if known)

We will acknowledge receipt within 48 hours and provide a timeline for a fix.

## Scope

This policy covers the code in this repository. For vulnerabilities in the
hosted ellul.ai service, email the same address.

## Disclosure

We follow coordinated disclosure. We will work with you on a timeline and
credit you in the advisory (unless you prefer anonymity).
