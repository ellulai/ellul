## Default Permission

Default permissions for native auth plugin

#### This default permission set includes the following:

- `allow-sign-in-apple`
- `allow-open-oauth-browser`
- `allow-register-push`
- `allow-haptic-feedback`
- `allow-copy-to-clipboard`
- `allow-share`
